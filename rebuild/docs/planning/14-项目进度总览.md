## 五、美术路线为什么改了四次

| 试过 | 为什么不行 |
|---|---|
| 1920 画布直接画 | 原作元素只有 40–60px，画大一倍，怎么都不像 |
| 矢量平涂 | 硬边＋黑描边，一眼现代 |
| 笔刷点点堆 | 定不住轮廓，糊成浆糊 |
| AI 厚涂重绘 | 风格漂移、不认尺寸，只能当人物/地表 |
| **原图切割＋放大** | **唯一做到「完全像」的路，因为就是原图** |

实测数据（记在 `art/04`）：快捷格 44px、状态条 40×18、说明框 430 宽、字号 10–12、
草地 RGB(112,136,43) 偏黄绿、饱和度 0.75、描边 1px 深棕。

## 七、卡点与风险

1. **六个二级面板无参考**：只能按主界面风格自己画，画出来是「推测」，不是复刻。
2. **版权**：D-06 之后入库的是原图像素，商用需另做授权评估。
3. **分辨率天花板**：源图 1606 宽，3 倍是上限；再高只是变糊。
4. **团队通道不稳**：美术与工程两个成员两次因网络中断失败，目前由我直接执行。
