## 三、每轮开工前必读（自动轮次照这个做）
1. 读本文件，确认这一轮查哪几个模块；
2. 读对应模块文件，**避免重复收同一事实**；
3. 派 2–3 个只读 agent 并行，各负责一个模块，**每个 agent 只准写自己那个模块文件**；
4. 回来后按 `README.md` 的规则筛选、去重、判冲突；
5. 写入模块文件，更新本文件的轮次与累计；
6. 发现新的待确认点，追加到 `docs/research/待确认.md`，**不直接改审核台**；
7. 并库前先按 README 第 2.6 条查一遍「同源转载」——**换站不换字不算第二来源**，别让同一段文字把 B 级抬成 A 级。
