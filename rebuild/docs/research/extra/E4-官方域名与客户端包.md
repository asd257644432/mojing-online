# E4 · 官方域名 `gamebean.com` 与客户端包 / SWF 专项

> 采集时间：2026-11-05 ｜ 采集人：gb-src
> 范围：官方主域 `gamebean.com`、官网 `mj.gamebean.com`、官方论坛 `bbs.gamebean.com`、静态资源站 `content.gamebean.com`、母体公司站 `ourpalm.com`；SWF / 客户端 / 服务端包 / 微端 的搜刮；音乐结论复核
> 不含：门户专区（E1）、百科问答台服（E2）、论坛长视频音乐（E3）、贴吧（T 轮）

**去重声明**：动笔前已读 `extra/README.md`、`research/README.md`、`E3-论坛与视频音乐.md`（含第五节「打不开的入口清单」）。E3 已记为 403 的两个入口本轮**重新做过协议/UA/Referer/参数/Host 头四类变体测试**，结论有修正（见 1.2），不是重复劳动。

**一句话结论**：域名这条线**挖穿了，但是空的**——`gamebean.com` 现在是掌趣「欢畅游戏」的手游门户，旧官网/旧论坛在这台服务器上**根本没有独立站点配置**（不是「打不开」，是「不在这里」），唯一活着的静态资源站只剩 2017 年以后的手游素材；**SWF / 客户端包全网零命中，没拿到**；音乐维持 E3 的「无文字记录可查」，结案。

### 1.2 关键发现：这是通配 DNS + 通配兜底，不是「WAF 拦了」

把请求直接打到回源 IP 并通过 `Host` 头切换站点，结果如下：

| `Host` 头 | 请求 | 返回 |
|---|---|---|
| `gamebean.com` | `http://120.132.83.46/` | **200**（30854 B） |
| `www.gamebean.com` | 同上 | **200**（31034 B） |
| `content.gamebean.com` | 同上 | **403**（103 B） |
| `mj.gamebean.com` | 同上 | **403**（103 B） |
| `nothing.example`（**不存在的主机名**） | 同上 | **403**（103 B，与 mj 完全同字节） |

**推论（三条，都很重要）**：

1. `mj.gamebean.com` 与 `bbs.gamebean.com` 在这台服务器上**没有独立 vhost**，落到的是默认站点 → 默认 403。
2. 因此**「403」既不能证明站点存在、也不能证明站点死亡**。E3-002（「官方论坛现已 403 Forbidden」）的**观察没错、读法要修正**：那 403 是通配兜底，跟论坛本身无关。
3. **子域枚举在 `gamebean.com` 上永久无效**——任意子域都解析到 `120.132.83.46` 并返回同一 403。以后任何人再看到「`xxx.gamebean.com` 403」，都不必再试。

### 3.2 为什么「拿不到」——三条原因，都是实证

1. **本作是纯无端页游，没有客户端包。** 17173《页游大片〈魔镜OL〉游戏前瞻》原文：「玩家不必花时间下载庞大的客户端就能随时随地体验游戏」。所以「客户端 / 微端 / 安装包」这个方向**从定义上就不存在**，不是我搜不到。
2. **本作从未被私服化。** 2011–2013 年的热门页游（神曲、龙将、傲视天地等）在源码站都有完整服务端包，本作在 iopq / 9ria / 淘宝 / 网盘 / 百度 全部零命中——说明当年没有流出过服务端，也就没有「私服改过的文件」可捡。
3. **官方文件已物理删除。** `mj.gamebean.com` 连 `crossdomain.xml` 都 404（这是 Flash 跨域策略文件，任何 Flash 页游站必放），说明站点目录被整个清空，不是「权限拦住了」。

### 3.3 还剩的可能性（写清楚，别让人再白跑）

- **唯一有理论可能的**：Common Crawl 的 CDX 接口恢复。只要它能返回 2011 年 `mj.gamebean.com/*` 的 URL 列表，就能拿到当时 `index.html` 里引用的 SWF/资源路径；若对应 WARC 段还在，就能把 2011 年的登录页 SWF 原样取回。**但前提是 CDX 先恢复，本轮 504。**
- **已排除的**：Wayback / archive.today / timetravel（全部不可达）；台服官网 `mj.i7was.com.tw`（E2 已判死）；官方论坛（这台机器上没有论坛程序）。
- **不建议再试的**：任何 `*.gamebean.com` 子域枚举（通配，永久无效）；4399 / 7k7k / 2144 / flash8（不承载 MMO）。

## 四、音乐结论（复核 E3，不改判）

- E3 已把六个音乐平台（网易云单曲/歌单/专辑、QQ、酷我、5sing）、素材站、外包线索全部清到零。本轮**没有新增反证，也没有新增正证**。
- 本轮唯一的补充是一个**结构性事实**：本作是纯无端 Flash 页游、无客户端包、无服务端流出（见 3.2），因此**没有任何「离线包」形式的音频载体存在于民间**。
- **最终判词（写死）**：
  > **本作音乐在公开互联网上没有任何文字记录可查——零曲名、零专辑、零歌单、零外包案例、零民间音频包。唯一带声音的载体仍是搜狐那三条宣传片（合计 5 分 40 秒，E3-004）。要拿到音乐只有两条路：人工听那三条视频，或等到能提取到 2011 年原始 SWF。**
- 本文件**不写任何推测的曲名、作曲、风格描述**。到此结案。
