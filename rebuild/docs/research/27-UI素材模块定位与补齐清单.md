# UI 素材模块定位与补齐清单

更新：2026-11-14。默认进可玩原型；按 F8 才显示虚线占位框，框内只有简体模块名。暂停继续细画窗口皮肤。

## 查看方式

打开本地游戏即可查看主界面。点底部角色、背包、技能、任务、好友、公会、国家、商城，或右上小地图、活动入口，查看对应窗口的模块位置。B/C/J/K/M分别打开背包/角色/任务/技能/地图占位窗口。Esc或“关闭”框返回主界面。

F8在“模块定位”和保留的可玩原型之间切换。已写入的原型窗口、任务、装备、商店、存档没有删除；本阶段的默认预览不显示这些数据和操作文案。没有截图依据的邮件、拍卖、设置入口不额外塞进主界面，它们的窗口分区已登记，可先查看对应截图。

## 坐标与依据

主界面基准为用户提供的1606×936截图。每个矩形记作x、y、宽、高，再按横纵比例映射到1920×1080的UI画布；相机1.5倍缩放不会改变UI位置。主界面框表示截图对应区域，不是新造的美术。

各弹窗矩形使用1920×1080画布坐标，窗口内的模块矩形是相对于窗口左上角的局部坐标。角色/背包/任务/商店有各自资料参考；好友、公会、国家、商城、邮件、拍卖、设置和活动缺少完整窗口图证，内部仅做分区预留，不能视为已还原的原作布局。

窗口参考包括IMG0109、IMG0119、IMG0267、IMG0309、IMG0046。原始主界面截图归档在art-library/01-original/user-ui-20261114/hud-module-reference.png。

## 单一布局来源

- 布局配置：game/data/ui/module-layout.json。

- 实机截图：resources/reviews/screenshots/ui-modules/。

素材补齐时保留模块ID与矩形，先把对应素材注册到asset预留路径，再替换该模块的占位绘制；不要把旧截图中的人物名、数值、场景一起贴入。某个模块若有多层或多状态，再在同一模块下拆分子资源。图标、人物、效果、窗口底图和动态文字分别保留。

### 为什么三条状态条不用 png

条要跟着数值变长，贴图只能定死一个长度。改用 `game/scripts/world/hud_bar.gd` 在 `_draw()` 里画：胶囊条 + 左侧 `HP/MP/EXP` 白字 + 右侧白字数值，一行画完。`module-layout.json` 里这三条标 `render: "code"`。

**之前两版都不像，原因写在下面，避免以后重犯：**

| 之前以为 | 逐像素量出来的事实 |
|---|---|
| 条宽 298（占满整个模块矩形） | 条只有 **53×21**，只占模块矩形的左边三分之一 |
| 行距 28（34 / 62 / 90） | 实际行中心在 **45 / 69 / 94**，行距 24.5，MP 差 4.5px、EXP 差 7.5px |
| 左端半圆、右端收成尖角 | **两端都是半圆**，是个完整胶囊 |
| 按比例填充、EXP 只填 29% | 原图三条**都是满槽**；数值 51.5%/29.7%/29% 与条长完全不成比例 |
| 颜色靠目测调 | 纵向色阶是**逐行采样**抄下来的，HP/MP/EXP 各 11–15 段 |

结论：原版的胶囊条只是装饰，信息全在数字上。复刻保留「满槽长得和原图一样」，同时按 `ratio` 把右边剩余部分画成空槽，让它真的能当血条用；`ratio = 1.0` 时与原图逐像素对齐。

### 三条的实测数据（基准 1606×936）

| 行 | 标签文字范围 | 条范围（含描边） | 数值起始 x |
|---|---|---|---|
| HP | 186–210，y 37–52 | 218–271，y 35–55 | 271 |
| MP | 181–207，y 62–76 | 215–268，y 59–79 | 282 |
| EXP | 176–205，y 88–101 | 216–268，y 85–103 | 269 |

原图 MP 的数值比标签低约 7px、HP 的高 2px，是手摆的，三行并不统一。复刻统一按行居中，不做这个不一致。

### 其余约定

- 重绘生成器 `game/tools/gen_hud_assets.py`，**不裁切原图像素**（守住 README 铁律），颜色形状按 `hud-module-reference.png` 观察后复刻。
- 尺寸按 UI 画布 1920×1080 反算，横纵比例不同：`1920/1606=1.1955`、`1080/936=1.1538`。只用一个比例会把高度算大 3%。
- 数值和等级数字是动态文本，不烧进图片。
- 头像内的人物仍是剪影占位，等真头像素材；圆环、内圈、细金线可以定稿。
- 三条状态条**已经接进可玩 HUD**：`world_hud.gd` 里原来两个纯色方块换成 `hud_vitals.gd`，走同一套 `hud_bar.gd`，游戏里看到的就是原版那种胶囊条。
- 离线对照：`resources/images/界面与图标/项目产物/验收/screenshots/ui-modules/hud-bar-compare.png`（上原图／下复刻）、`hud-bar-overlay.png`（半透明叠加，错位会重影）、`hud-bar-gauge.png`（按数值填充）、`hud-playable-preview.png`（装进左上角面板）。Python 复刻版在 `game/tools/preview_hud_bar.py`，改参数时与 gd 同步。

### 还没做的两处

- **原图 MP/EXP 两行后面压着一块金边面板**，里面有淡淡的金色小字（读不出来）和「29%」。它盖在数字下面而不是上面，看着像原版的经验浮层。复刻没画，因为里面的字无法辨认，画上去等于编。要不要补，需要定。
- 文字用的是项目统一字体（思源黑体），原版是一套更窄的黑体，所以同样字高下笔画略宽。要完全一致得单独找字体。

已接通的玩法逻辑包括普通怪受击后反击、1—10级任务、装备、药水、存档和离岛。它们不等于界面素材已经补齐。133级580,047,075经验为图证；其它等级的临时曲线仍属推定，见26号文档。
