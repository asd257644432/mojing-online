## 三、为什么「CDN 不封」也救不了这一轮

把逻辑说死，免得后来者重复推理：

1. 一张贴吧图的完整路径是 **tid → 楼层 HTML → `<img data-url>` 里的 HASH → 换域名取原图**。
2. 图片 CDN 只负责**最后一跳**。前三跳全在 `tieba.baidu.com` 上。
3. 所以 CDN 200 只能证明「**已知 HASH 的图能下**」，不能帮你**发现新 HASH**。
4. 唯一的例外是**列表页主题首图**：带首图的主题会把 `imgsrc…<HASH>.jpg` 直接写进列表 HTML。但列表页同样 403 —— 这条路本轮也断了。
5. 搜索引擎没有替代：Bing/360 的 500+ 条结果里贴吧图床 **0 条**（第 15、16 条）。

**一句话：这是「入口没了」，不是「通道坏了」。**
