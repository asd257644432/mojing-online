## 爬取情况

**爬了哪些吧**

| 吧 | 结果 |
|---|---|
| 魔镜online吧 | 主阵地。列表翻到 `pn=550`，共 12 页约 350 条主题；逐帖打开 43 个 |
| 魔镜online玩家吧 | 全吧只有 **25 条主题**（含置顶），全部看过 |
| 魔镜ol吧 | 空吧，只有一条「吧主招募」 |
| 魔镜传说吧 | 空吧，无主题 |
| 魔鏡online（繁体） | **打不开**，返回「抱歉，根据相关法律法规和政策，本吧暂不开放」 |

**怎么爬的**

- 吧首页 PC 版（`tieba.baidu.com/f?kw=…`）与单帖 PC 版（`/p/<tid>`）都是 JS 空壳，抓到的是导航栏。
- 改用手机版 `tieba.baidu.com/mo/q/m?kw=…&pn=N` 和 `tieba.baidu.com/mo/q/m?kz=<tid>&pn=0`，**全文可抓，楼层、日期、楼中楼都在**，本次 90% 的内容来自这个入口。
- 吧内搜索（`/f/search/res`）和手机搜索（`/mo/q/search`）都不可用：前者返回空壳，后者把 `qw` 丢了直接跳到「强化吧」。所以只能靠**翻列表看标题**逐帖点。
- 站外兜底：`site:tieba.baidu.com 魔镜online + 关键词` 走百度，命中极少，只有 3 条有效线索（其中一条挖出了「魔镜online玩家吧」这个之前不知道的吧）。

**整体判断**

这个吧**没有攻略帖**。350 条主题里约九成是水帖、签到帖、寻人帖、怀旧帖、同人小说，2013 年之后基本变成小圈子聊天板。真正的系统信息全部散在**新手提问帖的回复里**，一条帖往往只回答一个字（「融啊」「魔毯」「技能啊」），要靠上下文才读得懂。所以本轮条目数不多，但都是原话，没有一条是我推的。
