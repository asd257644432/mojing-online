## 〇、关于「贴吧来源」的说明（必读）

**⚠ 本节结论已于 02:40 被更正，请先读这段再往下看**：
下面写的「贴吧本体抓不动」**只对本代理当时的抓法成立，不是全局结论**。
另一路代理实测走通了**手机版入口**：`tieba.baidu.com/mo/q/m?kz=<tid>&pn=N` 能拿到完整楼层 HTML，
图片在 `data-url` 属性里；再用 `https://imgsa.baidu.com/forum/pic/item/<HASH>.jpg` 换域名取原图（`tiebapic` 的 `sign` 绑死 250px，改宽度只会返回占位图）。
**W093（城镇广场完整 HUD，800×417）与 W094（草地公会合影带彩翼，610×403）就是从贴吧楼层下来的**，不是媒体站图。
另有一条实测：**HTML 被 403 时，图片 CDN（imgsa／tiebapic／imgsrc）照常返回 200**，所以拿图不受封禁影响，卡点只在「枚举不出 HASH」。
正确的表述应是：**PC 版拿不到，手机版可拿，但限流严重。**

### A.2 原图取法（关键，别再用缩略图）

手机版页面里图片长这样，**只有 250 px 宽**：

```
http://tiebapic.baidu.com/forum/w%3D250%3Bq%3D100%3Bg%3D0/sign=<40位>/<40位HASH>.jpg?tbpicau=…&src=…
```

试错记录：
- 把尺寸段 `w%3D250` 改成 `w%3D580` / `w%3D9999` / `w%3D1920` → 一律返回 **238×238 占位图（4 262 B）**。`sign` 与尺寸段绑死，改尺寸即失效。
- `src=` 指向的「原图」`tiebapic.baidu.com/forum/pic/item/<HASH>.jpg` → 返回**同一张** 238×238 占位图。加不加 `tbpicau` 都一样。
- **正解：换域名，HASH 不变** →
  ```
  https://imgsa.baidu.com/forum/pic/item/<HASH>.jpg
  ```
  直接返回原尺寸，无需 sign、无需 cookie。实测：800×417（123 666 B）、610×403（500 630 B）。
