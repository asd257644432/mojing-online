## 一、为什么单独开一个目录

贴吧帖子的性质和其他网源不一样：

| 特征 | 说明 |
|---|---|
| 一手玩家口述 | 不是编辑整理的攻略，是当年真在玩的人回忆，**细节密度高**（术语、习惯叫法、踩坑点） |
| 楼层里藏信息 | 主楼常常只是问一句，真正的答案在 3 楼、7 楼、17 楼 |
| 时间戳可用 | 帖子发布时间能定位「这是哪个版本的事」，比正文本身还重要 |
| 图片是一手截图 | 老玩家当年截的界面、怪物、时装，**比媒体图更新、更接近真实游戏** |
| 可信度整体 B | 单人记忆会错，需要和已有 A 级资料对照 |

所以贴吧内容**先收在 `docs/research/tieba/` 下**，不直接写进 `M01–M12`。
原因：`M01–M12` 有模块代理在写，避免并发冲突；另外贴吧内容需要交叉验证后再并库。
**第 9 轮（跨模块去重）统一并进主模块文件**，并库时标 `（贴吧）` 来源。

## 二、爬哪些吧

| 吧名 | URL 形态 | 说明 |
|---|---|---|
| 魔镜online吧 | `tieba.baidu.com/f?kw=魔镜online` | 主阵地，优先 |
| 魔镜ol吧 | `tieba.baidu.com/f?kw=魔镜ol` | 可能是同一个吧的别名跳转 |
| 魔镜传说吧 | `tieba.baidu.com/f?kw=魔镜传说` | 原名，可能有 2010 年前的帖子 |
| 魔镜online台服吧 / 酷遊相关 | 尝试 | 台服玩家可能另建 |

**爬取姿势**（按优先级）：

1. 吧首页列表：`tieba.baidu.com/f?kw=XXX&ie=utf-8&pn=0` （`pn` 每页 +50，翻到底）
2. 精品帖：`tieba.baidu.com/f?kw=XXX&ie=utf-8&tab=good` ← **先爬这个，信息密度最高**
3. 单个帖子：`tieba.baidu.com/p/<tid>?pn=1`（`pn` 是楼层页，每页 30 楼左右）
4. 吧内搜索：`tieba.baidu.com/f/search/res?ie=utf-8&qw=关键词&kw=魔镜online`
   —— 关键词清单见第四节
5. 手机版兜底：`tieba.baidu.com/mo/q/m?kw=XXX`（PC 版被拦时试）

**注意**：贴吧对无头抓取有反爬。如果 `WebFetch` 拿到的是登录墙/验证码/空壳，
改用搜索引擎的 `site:tieba.baidu.com 魔镜online 关键词` 拿**摘要**，
摘要里能用的信息照样收，可信度标 C，并注明「仅摘要」。

## 三、收什么

### 收
- 老玩家对**具体系统**的描述：怎么强化、怎么合材料、宠物怎么抓、摆摊怎么收税、国战怎么打
- **游戏内术语**：玩家怎么称呼某个东西（跟官方叫法不一样也要记，做 UI 文案要用）
- **版本差异**：某年某月改了什么、台服和陆服哪不一样
- **踩坑与bug**：当年有什么设定很坑、有什么 bug 被利用
- **具体数字**：经验、掉率、价格、冷却、时间
- **游戏内截图**：界面、地图、怪物、时装、翅膀、技能特效

### 不收
- 纯情绪帖（「好怀念啊」「求回归」）——除非里面有具体设定
- 找号、卖号、私服广告、外挂广告
- 与本作无关的串楼（贴吧串楼极多，尤其被其它游戏玩家占领的时段）
- 2020 年后的「怀旧服」「重制版」讨论——**原作已停运，这些是私服或臆想**

## 五、输出格式

### 文字 → `docs/research/tieba/T1-*.md` / `T2-*.md` / `T3-*.md`

每条一个表格行，**必须带原帖线索**（能回查）：

```markdown
| 编号 | 结论（一句话说清事实） | 出处（吧名 + 帖子标题/楼层 + 日期） | 可信度 |
|---|---|---|---|
| T1-001 | 强化 +7 以后有概率掉级，玩家叫「爆星」 | 魔镜online吧《强化心得》3楼，2011-08-12 | B |
```

- 编号：`T1-001` 起，各文件独立编号
- 可信度：`A` 官方帖/吧主整理 ｜ `B` 玩家口述 ｜ `C` 仅搜索摘要
- **一条只写一个事实**，不要一段话塞五件事（后面并库要靠这个）

### 图片 → `resources/originals/network/images-web/tieba/`

- 文件名：`W093_tieba_<内容>.<ext>` 起，**接着 `index.md` 的 W092 往后编**
- 同时在 `docs/research/tieba/T4-贴吧图片.md` 里登记：编号、内容、原帖链接、尺寸、用途判断
- 拿不到的图不硬编，在文件的「取不到」一节记原因
