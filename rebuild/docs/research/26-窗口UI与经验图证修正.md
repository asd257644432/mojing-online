# 窗口 UI、镜头与经验修正

> 最新UI状态：按用户要求改为默认虚线框＋模块名字预览，先定义位置，后续补素材；F8切回保留的可玩原型。定位与素材状态以[27号清单](27-UI素材模块定位与补齐清单.md)为准。

更新：2026-11-14。

## 移动与视野

人物世界移动速度由 320 像素/秒降至 140 像素/秒；镜头从 1.0 拉近至 1.5，可见世界的宽、高各缩至原来的三分之二。镜头缩放不放大 HUD 或窗口。因为镜头也拉近了，屏幕上的投影移动速度约为旧版的 65.6%。这两个值是本次体验调整，不代表已考证原作速度。

## 窗口来源与边界

可用入口：B 背包、C 角色、J 任务、K 技能；商店在药水店 NPC 亚撒处打开。窗口可以通过顶部 X 或 Esc 关闭，标题条可以拖动。

背包采用六列五行的物品格、上方页签、下方货币与按钮。角色采用左侧属性、右侧人物和十个装备位。任务采用左侧任务列表、右侧目标、奖励与操作。药水商店采用商品行和底部出售区。技能窗口完整布局缺少原作图证，当前仅沿用同一窗口皮肤展示已接入的一项暂定技能，不宣称原作一比一布局。

主要参考：图库 IMG0109、IMG0119、IMG0267、IMG0309，以及 IMG0046 已清理的商店组件。浅金标题、金边和深橄榄半透明底来自这些参考。运行时使用独立文字和真实按钮，没有把截图的旧人物数值贴进界面。标题切片右端残留的旧关闭钮通过图集区域排除，避免重复 X。

尚未接入的背包页、VIP包、租用包、翅膀页被禁用；不以空壳冒充已完成功能。物品图标和人物预览仍需后续还原，人物预览明确显示“待还原”。

## 新增经验图证

用户提供的经验条截图明确显示：

- 当前等级：133。
- 本级当前经验：172,562,713。
- 133 升 134 级所需经验：580,047,075。
- 显示进度：29%。实际比例约 29.7498%，因此向下取整是与该截图相符的推断，尚不能凭一张图确认所有百分比的显示规则。

分母是本级升级需求，不是从 1 级开始的累计经验。只凭这个锚点，不能推导完整等级公式、满级上限、经验加成、怪物奖励或任务奖励占比。

旧表 133 级的需求为 7,386,866，约低了 78.5 倍。旧版“149 升 150 需要 3200 万”的定值无原作证据，已经撤销。旧表保留在 `_work/level-curve-before-133-evidence.json` 供核对。

## 当前代码如何处理未知等级

`game/data/level-curve.json` 仅把 133 级这一行标为“图证”。1—10 级保留之前的原型节奏；11—133 级以原型 10 级和图证 133 级做临时对数插值；134—149 级暂时按同一斜率外推，全部标为“推定”。这些插值、外推数字不能作为原作经验表传播，累计经验同样是推定。150 级上限也仍是原型配置。

高等级怪物和任务奖励没有整表乘以 78.5：那会把一个升级需求的误差错误地转嫁到所有经验来源。目前只有 1—10 级玩法经过闭环验证，高等级奖励平衡仍待更多经验条和获得经验记录核对。

后续应优先收集多个不同等级的完整经验条，以及同一角色击杀、交任务前后的经验变化；每条记录带等级、经验分子/分母、怪物等级及是否存在经验加成。先替换已知锚点，再讨论分段函数和升级时长。
