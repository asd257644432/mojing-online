## 三、怎么判断（自我整理规则）

### 1. 相关性
只收能落到「这个游戏怎么做出来」的事实：系统、玩法、界面、美术、数值、内容。
纯宣传口号、玩家情绪、运营公告里的营销话术，不收。

### 2. 冲突怎么处理

| 情况 | 处理 |
|---|---|
| 多来源说同一件事、细节小差 | 取可信度高的，其余记进「舍弃与冲突」 |
| 和已定稿基线明显矛盾、又不能用版本/地区解释 | **舍弃**，记原因 |
| 能用版本差解释（2011-06 前/后、台服/陆服） | 保留，标版本，**不判对错** |
| 明显错误（时间线矛盾、数值离谱） | 舍弃，记原因 |

### 2.5 「零命中」必须带检索范围（这条是被真事逼出来的）

写「没有」「查不到」「零命中」的时候，**必须写清是在哪个范围内没查到**。

反例（真发生过）：一个代理只读了两个采集文件，在里面找不到「坐牢」，就写了「坐牢零命中」。
但另外两个文件里都有——贴吧有「红名关进大牢、要国王保释」，界面模块有「监狱是独立场景、PK 值 3000 进、10 紫晶出」。
差点让下游以为这游戏没有监狱。

所以一律写成这样：

| 错 | 对 |
|---|---|
| 「坐牢：零命中」 | 「坐牢：在 E1／E2 两份资料内零命中；**别处有，见 M08-080～082**」 |
| 「音乐：没有」 | 「音乐：公开互联网无任何曲目记录；**不能推论游戏没有音乐**」 |
| 「贴吧没有地图资料」 | 「贴吧按标题与已读楼层未找到；**因吧内搜索失效，不等于不存在**」 |

**一句话**：没查到的是「某个范围内没有」，不是「这件事不存在」。
两者混为一谈，比漏收更危险——漏收以后还能补，写死了就没人再查了。

### 2.6 「同源转载」不算第二来源（第 6 轮踩出来的，比 2.5 更容易骗人）

**同源转载** ≠ **多来源互证**。后者能提高可信度，前者只是同一段文字被换了几个站名。

| 假互证 | 真相 | 怎么判 |
|---|---|---|
| 百度百科「魔镜传说」× newton 百科「魔鏡傳說」 | **逐字相同**，是同一份文本 | 两页段落逐字比对，同字即同源 |
| 聚侠《公会战》× 其它站「公会战」 | 聚侠页尾写「来源：07073」，正文与 07073 **同字** | 看页尾「来源/作者」字段 |
| 聚侠 2011-06-22 × 07073 2011-06-28 | 同一篇玩家稿的两次转载 | 换站不换字＝一次采集 |

**三条硬规矩**：
1. **判来源真伪先看页尾**：「来源：厂商」「文/07073」「责任编辑」这些字段一眼能定同源。
2. **同一事实若只有同源转载，可信度按单源算**（通常是 B），**不能因为“三个站都写了”就升 A**。
3. **查无原件时要写成否定项**：聚侠 7358 引「17173 查无此稿」→ 正确的写法是「聚侠转载，17173 集内未查到」，**不是把聚侠列成 17173 的来源**。这条错了会让下游以为“有官方背书”。

### 3. 去重
同一「事实」只留一条。多个来源支持同一事实的，合并成一行，出处写多个。

### 4. 可信度

| 级 | 标准 |
|---|---|
| A | 厂商稿、官方专区、百科，且正文已抓到 |
| B | 玩家攻略、玩家问答、论坛帖 |
| C | 只有搜索摘要，正文没抓到 |
| X | 串游戏、噪声、AI 假稿（**直接舍弃，不进条目**） |

### 5. 不编造
抓不到正文就标「仅摘要」；数字查不到就写「未查到」，**不许用同类游戏套**。

### 6. 搜索怎么做（重要，每轮都照这个来）

**除了内置搜索，必须用多引擎交叉搜**——很多 2011 年的老稿只被某一家收录，
单靠一个搜索源会漏。直接 WebFetch 这些地址（中文查询用国内引擎）：

| 引擎 | 地址模板 |
|---|---|
| 百度 | `https://www.baidu.com/s?wd={关键词}` |
| Bing 中国 | `https://cn.bing.com/search?q={关键词}&ensearch=0` |
| 360 | `https://www.so.com/s?q={关键词}` |
| 搜狗 | `https://sogou.com/web?query={关键词}` |
| 搜狗微信 | `https://wx.sogou.com/weixin?type=2&query={关键词}` |

**定向站点**用 `site:`，例：`site:17173.com 魔镜Online 宠物`、`site:07073.com 魔镜OL 翅膀`。

**精确匹配**加引号：`"魔镜Online" "宠物"` —— 这一步很关键，能把同名游戏挡在外面。

**排除噪声**用减号：`魔镜Online 宠物 -飞天历险 -Mirage -魔镜物语`。

**节奏**：每次抓 3–4 个引擎，中间隔 1–2 秒；遇 403／429 先抓一下引擎首页拿会话，再重试。

> 微信公众号那条（搜狗微信）值得单独试：2011 年前后的页游老玩家常写回忆文，
> 里面可能有官方稿没写的细节。

**实测反馈（第 2–3 轮累计，这条很重要）**：

- **360**：会弹验证码，抓不到结果。
- **搜狗 + 搜狗微信**：对本作**基本无效**——「魔镜」这个词被 CorelDRAW 插件、电商数据公司、
  成人站点占满，翻几页都出不来一条游戏内容。
- **Bing 中国**：同样被同名噪声淹掉。
- **真正出货的是：内置搜索 ＋ 百度 ＋ `site:` 定向**
  （如 `site:17173.com`、`site:07073.com`、`site:baike.baidu.com`、`site:juxia.com`）。
- **结论**：优先用内置搜索和百度，再用 `site:` 定点翻老站；搜狗系和 Bing 只在补漏时试，别指望。
  同名噪声大时，仍然要「加引号 + `site:`」双管齐下。
