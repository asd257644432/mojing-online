### 6. 属性面板的完整字段

一张 19 级法师的面板，把顺序和分段全露了：

名称 / 称号 / 等级 / 国家 / 职业 / 公会 / 荣誉 / PK值 / 生命 / 魔力 / 经验 / 物攻 / 魔攻 / 物防 / 魔防 / 命中 / 回避 / 物理暴击 / 魔法暴击 / 八种抗性 / 力量 / 敏捷 / 体质 / 智力 / 精神 / 配点

两个关键细节：

- **攻防都是两段显示**，比如「物攻 2716 +8224」，前段是基础、后段是装备加成。
- **抗性确实是八种**，原文写着「八抗性」：灼烧、冰冷、混乱、眩晕、致盲、中毒、沉默、虚弱。
- 暴击确实分两行，那张图上物理 0%、魔法 11%，**双暴击坐实**。

### 7. 职业页签写的是「射手」

商店的六个页签原文：戰士、商人、盜賊、**射手**、法師、祭司。

加上创角界面的「弓」，一个职业现在有三种叫法：游侠（文档）、射手（商店）、弓（创角图标）。
