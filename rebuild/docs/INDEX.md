# 项目资料索引

更新：2026-11-15。项目总体说明见 [根目录 README](../README.md)。图片和文字素材统一在 [根目录素材总览](../resources.html) 检索；本地删除与恢复见 [素材管理说明](../resources/README.md)。

## 文档归类

- `decisions/`：用户原话、审核结论、关键决策、待确认事项。
- `planning/`：项目规划、施工方案、进度与验收。
- `research/`：玩法与截图考据、素材文字提取、资料补查。
- `art/`：画风、素材规格、UI 分块、地图复刻记录。
- `design/`：事实基线、核心循环、玩法规则与数值框架。
- `architecture/`：工程边界、实现方案和根目录整理记录。
- `18-全量截图文字台账/`：原始截图逐张解读。
- `ui-module-materials.csv`：UI 模块与素材登记。

## 素材实体位置

收集与生成图片在 `resources/images/用途/来源/…`；原始文字在 `resources/texts/主题/来源/…`，音频、压缩包、字体、辅助索引分别存放。IMG 编号和旧新路径对照保留，第三方仓库内部不改动。

`game/assets/`、`map-editor/assets/`、`assets/art/` 仍承担运行或构建职责，在统一总览可以一起查看。旧审核与失败模型 HTML 已清理，历史文字记录保留在 `_archive/`，不作为当前入口。
