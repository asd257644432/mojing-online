## 三、试错记录（避免重复踩）

| 试过 | 为什么不行 |
|---|---|
| 在 1920 画布上画细节 | 原作元素只有 40–60px，画大了一倍 |
| 纯矢量平涂 | 边缘太硬、描边太黑，一眼现代 |
| 笔刷全靠透明笔点堆 | 定不住轮廓，糊成浆糊 |
| 把原图喂给 AI 图生图 | 会带入原像素，且每次结果不同 |
| 压缩到 24 色以上去噪 | 图标细节被抹平 |
| 中值滤波 3×3 去 JPEG 噪点 | 小图标会糊，改用 Lanczos＋轻锐化 |
