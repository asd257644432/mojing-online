# 根目录与素材整合说明

更新：2026-11-15。统一网络与用户素材，按用途整理实体文件路径，提供图片、文字检索及本地同步删除。

## 当前目录

- `resources.html`：根目录完整总览，双击可离线浏览。
- `启动素材管理.cmd`：本机管理服务，提供删除、回收、恢复和重扫。
- `resources/images/`：图片按用途、来源分类；保留原文件名与制作阶段。
- `resources/texts/`：用户游戏资料、网络帖子、逐图提取、制作说明和来源清单。
- `resources/audio/`、`packages/`、`fonts/`：音频、资源包与旧程序附件、字体。
- `resources/metadata/`：历史索引、提取和生成记录；`resources/_catalog/` 是浏览缓存。
- `resources/third-party/`：完整第三方项目，内部保持原样。
- `game/`：Godot 工程、运行资源、数据、代码和当前导出。
- `map-editor/`、`map-editor.html`：地图编辑器源文件和当前离线页面。
- `assets/`：生产素材与登记表，保持构建路径。
- `docs/`：decisions 决策、planning 规划、research 考据、art 美术、design 玩法、architecture 架构、18-全量截图文字台账。
- `_tools/`：工具；`_work/`：依赖、临时工作和核对记录；`_archive/`：历史资料与素材回收区。
- `.workbuddy/`：项目设置；`README.md`：项目说明。

## 实际迁移和清理

第一轮将原根目录收集、切片、重绘和截图归入 resources，迁移 5,177 个文件。第二轮按实体类型和用途再迁移 3,780 个文件，含 24 份项目文档，不只是改变网页标签。图片进入 images，文字原料进入 texts，音频与资源包分别归位，辅助 CSV/JSON 进入 metadata。旧空目录结构归档到 `_archive/empty-resource-layout/`。

最后盘点发现新增“外部移入待整理/人物3D模型”，另迁移 8 个文件至 `resources/models/人物与造型/来源待核/人物3D模型/`，保留模型、两个查看页及相对依赖。它属于外部移入待核素材，没有恢复或重新制作先前已删除的失败模型。对照记录是 `late-intake-moves.json`。

同内容合并展示，所有实体副本列在详情。迁移不自动删除图片或文字原件；按用户要求清理了 **21 份过时生成 HTML**：旧审核台、旧 UI 总览、失败模型预览、临时导出、旧入口及其 HTML 备份。当前地图编辑器、游戏导出、构建模板和第三方原始页面保留。之前被要求删除的 3D 模型没有恢复。

原图片内容指纹和历史 IMG 编号保留；文本原始证据不改内容。项目维护的引用、索引和文档链接随路径更新。游戏、地图编辑器和生产素材保留运行路径，并统一入总览。

## 删除和恢复

页面仅允许选择 resources/images、texts、audio、video、packages、models 内已索引的具体文件。确认框列出路径，服务核对内容后移入 `_archive/resource-trash/`，重建根 HTML、JSON、CSV。失败会回滚文件移动。未勾选副本不受影响。

回收区不再收入素材总览，可在页面恢复到原路径，恢复不覆盖已有文件。回收能力暂不永久释放磁盘空间。运行代码、项目文档和第三方依赖不开放删除。

服务仅监听 127.0.0.1，检查 Host、请求来源和会话令牌，拒绝任意路径、越界、符号链接与目录联接。离线 HTML 可以检索，不能执行本地删除。
