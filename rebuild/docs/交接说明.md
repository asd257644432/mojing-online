# 魔镜Online 网页复刻 · 交接说明

新对话先读这一份，再动手。写于 2026-11-15。

## 一、用户定下的规矩（不要再问）

- 沟通：大白话，技术词用形象说法当场解释；要用户做决定时给 A/B 和各自代价；表格别太宽。
- 忠于原作：有原作截图就照原作；没图证的内容标「暂拟」，不许编造后当成原作。
- 进游戏的文字一律简体。繁体是台服内容，只作参考。
- 不用以前其它 AI 做的地图和模型，看到就删。美术由我照原作截图风格重画。
- 画面：比原作清楚约一倍即可，保持 Q 版老页游味道，不做成现代游戏。
- 操作：只用鼠标点地走路，不要 WASD；自动寻路；Tab 选最近的怪；玩家永远在画面正中。
- 人物动画故意低帧率（复古），其余按 60 帧。
- 联网多人：服务器当裁判并保存数据，目前开在本机。
- 换装：衣服整套换图，按等级段（1 级、10 级、20 级…）每段一套；武器单独外观；时装是一整套。
- 头和身体分开画：头 = 脸 + 发型，身体 = 衣服 + 动作。发型和发色照原作创角界面。
- 攻击动作按职业区分：战士挥剑劈砍、商人抡锤、游侠射箭、法师和祭司抬杖施法。
- 飞毯、彩云等飞行器上人物站着不跑动。
- 1 到 10 级全程约 20 分钟。
- 省用量：一次只做一个样品，用户点头再铺开；一张图画满一整套；界面和特效用代码画；
  图片由用户自己打开把关，我少看图；阶段性另开新对话。

## 六、怎么自测

本机 PATH 里没有 node，用这个：
`%USERPROFILE%\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin\node.exe`

Python 在 `%LOCALAPPDATA%\Programs\Python311\python.exe`，只有 pillow 和 numpy，没有 scipy。

拍截图（测试服用 8099，存档放临时目录，不碰正式存档）：

```
$env:MJ_SAVES="$env:TEMP\mj-test-saves"
Start-Process node -ArgumentList "web\server\server.js","8099" -WindowStyle Hidden
node web\tools\shot.js "http://localhost:8099/?auto=名字,1234,warrior" 输出.png 6
```

第四个参数可以写一句页面里执行的代码，比如 `"toggleWin('bag');1"` 先打开背包再拍。
网址里的 `?auto=名字,密码,职业` 会自动登录，名字没用过就自动创建。

量通关时间：`$env:MJ_SPEED=8` 开测试服（8 倍速），再跑 `node web\tools\bot_test.js 8099 warrior`。

## 七、踩过的坑

- 服务器不能挂在 AI 的后台任务上，回合一结束就被收走。要用 Start-Process 开独立窗口，或让用户双击启动脚本。
- 启动脚本必须是纯英文内容加 Windows 换行，否则双击没反应。
- Edge 的 `--screenshot` 命令行拍照会在游戏还没连上时就拍，所以改用 shot.js。
- 生图工具时好时坏，报错重试即可；出图是白底，由切图脚本去底。
- 主角图集五列的朝向是：正面、左前、左侧、左后、背面。朝右的三个方向在游戏里照镜子翻转。
  chars.json 里 dirs 那一栏写的方向名是错的，以这里为准。
- 找主角头的位置用「整个剪影里最大的圆」，用肤色找会被眼睛打断。
