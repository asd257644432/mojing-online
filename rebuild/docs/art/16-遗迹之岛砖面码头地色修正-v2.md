# 遗迹之岛 v2：按用户标注修正

用户标注蓝框遗迹地面应为砖而非碎石，红框码头有变形，黄框和其他地面分块存在明显深浅衔接。

本轮修复：遗迹改为矩形砖铺地；码头重新绘制，取消纵向压缩，采用刚性等比配准；村子、麦田、两类树林的底色通过透明遮罩分离，各区共用原生草地，不再叠加矩形草地色块。普通景物保留 v1 的原生主体 RGB，避免背景提取导致主体颜色和位置变化。
