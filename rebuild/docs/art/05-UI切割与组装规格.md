## 二、拼装方法

1. 建一张 1606×936 的透明画布，等比放大到目标分辨率（1920 用 1.196 倍）。
2. 按上表 `x,y` 乘以同一倍率，把每件贴回去。
3. 圆形件（头像、小地图）已带透明通道，直接叠；其余为矩形件，边上 1px 草地可忽略。
4. **动态内容不切**：数字、名字、聊天文字、任务文字由程序绘制，图里只保留底框。

## 三、本轮验证

- 按原坐标把 15 件贴回，位置与原图一致（`r2-review/ui-cut/assembled-check.png`）。
- 每件 3 倍、轻锐化，边缘不糊（`contact-sheet.png`）。

## 四、已知问题

| 问题 | 说明 |

| 字号 | 原图正文 10–12px，3 倍后 30–36px，重组时若画布放大 1.196 倍需按比例缩放 |
