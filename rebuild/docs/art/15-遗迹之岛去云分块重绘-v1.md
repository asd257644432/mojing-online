# 遗迹之岛：近景分块重绘与全岛去云

本轮从用户原始照片的村子裁块开始，使用内置 imagegen 重绘，不再将约一千像素宽的整张导航图简单放大作为游戏近景。

五个重点块：村子、两块相接的麦田、椰树林、东侧树林、遗迹。另绘制十二个地形块。阶段比较均以原图同一区域和相同比例展示，位于 `resources/reviews/screenshots/island-redraw/`。麦田误画的海水经过额外修订；第一轮拼接的明显矩形色差与岸线断口没有作为最终场景交付。

最终文件：`map-editor/assets/island-redraw-v1/island-scene-6012x3594.png`；详情见该目录 README。十二个最终地图块来自这个主图，已逐像素比对一致。编辑器已接入同尺寸 WebP 预览，增加区域近景定位及内嵌阶段对比，逻辑坐标仍为原图 1002×599。

白云、地图文字、玩家/NPC/怪物覆盖标记已从最终场景中去掉。海岸使用原有原图坐标轮廓统一拼合，云遮挡处只有相邻海水、沙滩、地面的保守延续；精确原貌仍未得到证实。重点景物的新增像素细节为重建，不能声称像素级原作还原。

Godot 新增 `game/scenes/ruins_island_redraw_v1.tscn` 背景场景，原有运行入口和碰撞/生成逻辑没有替换。新增场景未在 Godot 引擎中运行；资源路径已静态校验。烘焙景物的前景遮挡需要后续拆分，避免误认为所有游戏功能已经完成。

验证：`_work/island-redraw/verification.json`，以及 `_work/map-editor/browser-test-report.json`。最终美术对照由人工视觉检查，不能以文件分辨率或云像素检查替代还原度评估。
