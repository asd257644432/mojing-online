# 村落围栏穿模修正

2026-11-14。用户指出栏杆穿入房屋，实际近景核对属实。前版 210 项检查只覆盖物件范围和导航，漏掉局部渲染遮挡；不应把其通过解释成画面无误。

原因：整圈栏杆只分前后两大块，前半块以最南端统一排序，导致本应在房屋后方的局部栏杆绘制到墙面。房屋周边也只有圆形碰撞，不能代表墙脚。

修正：

- 原图布局、小屋/摊位位置与比例保持不变，不移动建筑掩盖问题。
- 读取原围栏图的 alpha，将其分为窄片，分别按每片实际底部落点排序。图像像素未修改，使用同一张纹理的区域引用。
- 墙脚区域内的栏杆由统一遮挡材质裁掉，栏杆不再从墙面、门口和摊位底座中穿出。
- 遮挡按建筑实际 alpha 轮廓取样，不用大矩形挖空栏杆；使用围栏纹理坐标定位，避开网页缩放/合批下的模型矩阵差异。原生近景与最终网页均已目视核对。
- 地面碰撞使用房屋/摊位实际墙脚范围；屋顶、篷布的视觉遮挡与地面碰撞分别定义。
- 建筑内的隐藏围栏碰撞取消，该范围由建筑自身阻挡。两个原有通行口继续保留。
- 增加实际相交片段的深度顺序回归、建筑墙脚阻挡检查；检查总数 411，0 失败。可走格全部连通，出入口、NPC 与区域路线通过。

结果：`resources/images/地图与场景/项目产物/验收/screenshots/ruins-island-fence-fix/before.png`、`after.png`。全岛总览和 Web 包同步更新。此前 v3 的三联对照图是历史画面，当前穿模修正以本记录近景为准。
