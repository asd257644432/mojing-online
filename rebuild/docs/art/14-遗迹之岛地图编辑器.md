# 遗迹之岛：原图清理与可编辑地图工作流

2026-11-14，用户要求从原始照片直接清图、使用真实坐标放大，并建立 HTML 编辑器。旧版分层房屋/围栏重建没有获得用户认可；本次采用原图底稿与独立逻辑层，不继续拼装旧版美术。

交付入口为项目根目录 `map-editor.html`，详细说明见 `map-editor/README.md`。编辑器离线可用，所有资源内嵌，支持障碍绘制、NPC/怪物范围、密度/数量、标定、存档、PNG/JSON/CSV/TSCN 导出。

原图仍是 1002×599，清图候选局部有 AI 重绘偏差，不能作为逐像素一比一复原的验收结果。编辑器提供原图对照与局部仿制修补，并保留所有原始文件。

用户新提供 NPC 列表照片，确认十个 NPC 的游戏坐标；尚缺地图圆点与名字的对应确认。因此交付 HTML 默认无标定、无 NPC 自动投放、无推定怪物数量和障碍。标定后可按资料坐标批量放置 NPC。当前 Godot 游戏文件和旧地图数据未替换。

已进一步根据十个 NPC 的圆点分布得到仿射候选，像素 RMS 0.398，最大残差 0.497。候选可以在编辑器中点选套用，但保持“待核对”状态，需额外已知位置验证。候选并非原作命名点位的直接图证；默认不会替用户确认。
