## 怎么去文字和旧场景

没有用颜色阈值硬抠，也没有整块重画。做法是：

1. 每个部件先按"外圈描边保留原像素、只处理内部填充"划出处理区。
2. 用中值差分把文字、图标这类高频内容标成掩膜，不参与拟合。
3. 剩下的干净像素做 Tukey-IRLS 多项式拟合（2–3 阶），得到材质本身的渐变；旧场景的大块明暗属于拟合阶数之外的内容，自然被抹掉。
4. 底色层因为被商品行、按钮大面积遮挡，只用"没被压住"的可见像素参与拟合，再向遮挡区外推。

这样边框、圆角、线宽全部是原像素，只有内部填充是重建的。

## 透明度怎么定的

单张截图里 C = α·F + (1−α)·B，B（旧场景）未知，α 和 F 不能同时唯一解出。所以：

- 取 B = 70（中性参考底）作为统一基准；
- 按各材质的可见条纹对比度估 α：底色 0.70、页签条 0.80、商品行 0.86、图标槽 0.92、出售槽 0.92、按钮与标题条与外框 1.00；
- 反推 F = (C − (1−α)·70)/α，并把 α 写进 PNG 的 alpha 通道。

**所有 α 都是估计值。** 四背景（浅色／深色／草地／雪地）检查通过：面板在任何底上都读作"带自身底色的半透明板"，没有残留旧场景，没有抠图白边。

## 用了混元模型的地方

只有一处：底色层的材质纸纹。原面板自身的纹理已经被旧场景整片盖过，物理上无法反推，只能补。做法是生成一张极低对比的做旧纸纹，转成亮度场后限制在 ±5% 以内乘到底色层上，输出为 `02-body-panel-grain.png`。

- 默认交付的是**无纸纹版**（`02-body-panel.png`，纯平滑渐变），诚实版。
- 带纸纹版单独一份，清单里标 `推定补绘·非原版像素`。

除此之外没有任何一处用生成图替代原像素。

## 推定与欠缺

推定（不是原版像素）：所有 α、底色层纹理、页签选中态底形、右向翻页箭头的镜像、外框右侧 4px 外缘、关闭钮顶部圆弧、图标与货币的软边 alpha。

欠缺（没有就是没有，不编）：悬停／按下／禁用态一张都没有；图标暗部在洋红槽底上仍有轻微残留；底色是单一纵向渐变，横向的轻微明暗差没有还原。
