# 极简编辑器与十个人物坐标预置

用户反馈原编辑器复杂，要求极简且精致的界面，按两张参考图计算比例、放置全部人物并使用简体字。

## 结果

默认只展示主地图、选择/人物/怪物/障碍四个常用入口、人物列表和保存/导出。选中对象后才展示其属性；复杂图层、完整工具与标定保留在高级弹窗。地图空白处可直接拖动，选择人物不会制造空的撤销记录。默认镜头适合整座岛，右侧面板可收起。

人物使用编号标记，避免村子中密集姓名互相遮挡；姓名与坐标在右侧完整显示。人物、怪物目录和自定义文本转为简体。原始游戏 JSON 和证据照片不覆盖。

## 坐标依据

用户本次图 2 与 `map-editor/assets/original.jpg` 的 SHA-256 一致，实际尺寸 1002×599。图 1 提供十个名称和游戏坐标，与项目原始列表一致。利用圆点分布建立十组对应并做仿射拟合，原图像素 RMS 0.39784，最大 0.49664。名称与点位匹配来自整体分布，尤其绿色商店点与药水店坐标对应；没有把玩家箭头/蓝色图标当成人物圆点。

游戏坐标到原图像素约为：

```
sourceX = 12.49735644 * gameX - 0.00389858 * gameY + 80.03183191
sourceY = -0.00511840 * gameX + 6.24598513 * gameY + 51.37652214
```

默认人物位置由逆向拟合矩阵换算，输入的十个游戏坐标保持精确回算；圆点位置误差小于 1 原图像素。原图横/纵单位约 12.4974 / 6.2460 像素，六倍场景约 74.9841 / 37.4759 像素，约 2:1。界面「比例」可查看，`map-editor/npc-layout.json` 可供运行时集成参考。

## 验证

浏览器实际点击人物编号、编辑游戏坐标并撤销、添加繁体输入名称后检查简体转换、删除人物、拖动空白地图、创建怪物范围并修改数量、绘制/隐藏障碍、打开高级导出、保存 JSON、导出独立 HTML 后再次打开，以及 390 像素宽与桌面布局均已验证。图片在 `resources/reviews/screenshots/minimal-editor/`，报告在 `_work/minimal-editor/verification.json`。原有高级功能回归和几何单元检查也通过。

本轮没有替换 Godot 游戏运行入口或逐物体遮挡，只更新编辑器与坐标导出数据。
