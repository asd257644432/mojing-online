## 本轮交付

- 世界范围 6144×4096 像素；导航格 32px，共 192×128 格。
- 六区域：西南村落、西北金色麦田、中北棕榈林、东侧大蘑菇区域、东南圣迹滩、东北栈桥出口。
- 46 个独立物件：小屋、摊位、围栏、棕榈、树木、遗迹；按脚底高度与人物/怪物排序。
- 地面布局与细纹理分离；近景补充草地、土路、沙地与石地细节。
- 10 个现有 NPC 名称作为标记摆入村落。原始 NPC 表不修改，像素位置为推定映射。
- 24 只现有怪物分到原图四个区域，每种 6 只。高等级区域保留对应怪物，不用低等级怪替换全岛。
- 海水、树干、建筑、围栏与遗迹基座阻挡；人物与怪物检查同一份可走性。
- M 打开全岛地图并标示角色位置；M/Esc 关闭。正常游戏相机仍保持人物居中。
- 东北出口有动态圆环与 10 级提示；跨图目的地未制作，不假装已接通沐光平原。
- 原尺寸全图合成 PNG、阶段图、Godot 场景、数据和新版 Web 导出包。

## 文件与重建入口

- 运行资产：`game/assets/maps/ruins-island/`。
- 布局与来源状态：`game/data/world/ruins-island.json`。
- 布局生成器：`_tools/build_island_layout.py`，只生成数据，不绘制/编辑图片。
- 场景组件：`game/scripts/world/ruins_island.gd`；地形接入在 `world_terrain.gd`，其他地图保留旧地形。
- 验证：`game/tools/test_island.gd`，失败非零退出。
- 截图：`game/tools/capture_island.gd`，从实际 Godot 场景渲染 PNG。
- 全尺寸合成图：`resources/images/地图与场景/项目生成/生成/ruins-island-v1/full-map-6144.png`。无区域标注，保留出口自身游戏文字。
- 图示：`resources/images/地图与场景/项目产物/验收/screenshots/ruins-island/ground.png`、`02-village.png`、`final-all.png`、`final-village.png`、`final-ruins.png`、`web-gameplay.png`、`web-overview.png`。

运行 `python game/tools/serve_web.py 8080`，网页点 ENTER WORLD。当前 8080 已有该服务器。

```powershell
python _tools/build_island_layout.py
Godot_v4.7.2-stable_win64_console.exe --headless --path game --editor --import --quit
Godot_v4.7.2-stable_win64_console.exe --headless --path game --script res://tools/test_island.gd
Godot_v4.7.2-stable_win64_console.exe --headless --path game --export-release Web build/web/index.html
```

截图使用实际渲染后端，不使用 headless 虚拟渲染：

```powershell
Godot_v4.7.2-stable_win64_console.exe --path game --script res://tools/capture_island.gd -- --phase=all --out=C:/Users/zheng/Documents/mjol/_shots/ruins-island/final-all.png
```

phase 支持 ground/village/all/palms/grove/ruins/pier/gameplay/gameplay-ruins/export。export 从 6144×4096 SubViewport 输出全尺寸合成，不影响游戏运行时分层。

## 验证范围

结果见 `_work/ruins-island/test-report.json`、`web-run-report.json`；最终检查数以报告为准。

- 全部可走格从出生点连通。围栏/遗迹交叠曾留下 2 个封闭小格，现标不可走并记录数量；不是删掉整块区域来掩盖不通。
- 六区域与出生点组成 21 对路线，另有 40 个固定种子的陆地抽样点，逐段采样检查不穿阻挡。
- 实际 CharacterBody 沿路线到达各区，误差要求 ≤8px。
- 10 个 NPC 锚点可达；24 只怪生在各自区域且不在阻挡中，拒绝进入海水。
- 近岸海水点击吸附到陆地，远海拒绝。修复旧寻路“吸附目标后又追加原始阻挡终点”的问题。
- M 开关地图、图幅适配和人物标记坐标。
- 隔离 Edge 无头浏览器运行 Web 包：进入游戏、打开/关闭地图、点击行走，截图检查；控制台无错误，PCK Range 206，COOP/COEP 正确。

本轮未做全部职业/全部地图回归、长期性能测量或多人测试。
