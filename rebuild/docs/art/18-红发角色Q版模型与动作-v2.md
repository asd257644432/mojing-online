# 红发角色 Q 版模型与动作 v2

状态：**待审样稿**。v1 被用户指出“不够 Q 版”；v2 重新查阅项目根目录中的原图后调整。尚未替换正式游戏的方块角色。

## 本轮已定需求

- 真实可编辑的三维模型、骨骼与动作；同时输出八方向透明动画，供当前 Godot 2D 项目使用。
- 外形忠于用户提供的红发、绿眼、裸上身、深蓝短裤、赤脚截图。
- 少帧播放：站立与跑步循环；攻击与施法播放一次；死亡是倒地并停住。
- 武器范围：剑、匕首、弓、法杖、权杖、锤子。
- 需要劈砍、向前探步刺、射箭、抬杖施法与锤击。

完整的帧数、播放速度、八方向顺序、定位点和动作名称，以 `game/assets/characters/redhair-v2/manifest.json` 为准。

## v2 的修改

- 腿部相对建模初稿缩短约 27%，躯干缩短约 14%；头部保留完整体积并略调整，减少长腿玩偶感。
- 将身体皮肤连成连续表面，保留骨骼权重，消除拼接球形关节。
- 眼睛改为较平的上沿、小高光和更大的绿色虹膜，收小嘴线。
- 红发增加不对称碎发与弯曲发束；深蓝短裤改为平直短裤轮廓。
- 八方向由同一个三维角色分别渲染，没有镜像替代；持武器的手不随左右朝向交换。
- 增加弓弦拉动与箭矢释放；武器与手臂动作烘成普通骨骼动画。

截图没有展示侧背面、这些武器的完整款式或连续动作；这些部分仍是**推定补设计**。外形尚待用户验收，不声明已经达到一比一复原。

## 文件与查看方式

- 可视预览：`resources.html（旧页面已清理，使用当前素材总览）`，可离线打开，切换武器、动作、朝向、大小及单帧。
- 可编辑母版：同目录 `source/redhair.blend`。身体、发束、眼睛和武器可编辑；武器作为独立网格保留。
- 基础角色：`source/redhair.glb`。六个带武器的版本为 `redhair-sword.glb`、`redhair-dagger.glb`、`redhair-bow.glb`、`redhair-staff.glb`、`redhair-scepter.glb`、`redhair-hammer.glb`，每个版本只包含对应武器，避免打开时所有武器叠在一起。每个 GLB 都包含动画，使用与该武器同名的动作组。
- Godot 图集及 `SpriteFrames`：`game/assets/characters/redhair-v2/`。
- 独立 Godot 预览场景：`game/scenes/redhair_preview.tscn`。
- 可复用显示组件：`game/scripts/world/redhair_visual.gd`，放在角色节点下，原点为脚底；支持换武器、朝向、跑步、攻击、倒地与复活显示。
- 检查结果：美术目录 `verification.json`；Godot 检查日志位于 `_work/redhair-godot-smoke.log`。

武器动作不包含魔法粒子、飞行箭矢或战斗伤害判定。它们属于后续游戏接入，不在模型贴图中固定。

## 重建与检查

使用 `_work/tools/blender-python` 中的 Blender 4.2 Python 包，未调用图片生成接口，未把参考截图像素贴到模型上。

```powershell
python _tools/build_redhair_character.py
python _tools/export_redhair_variants.py
python _tools/package_redhair_character.py
Godot_v4.7.2-stable_win64_console.exe --headless --editor --path game --quit
Godot_v4.7.2-stable_win64_console.exe --headless --path game res://scenes/redhair_preview.tscn -- --smoke-character
```

画布扩大用于完整容纳左右方向的倒地姿势，人物的渲染像素密度保持一致。构建脚本可从源模型重建全部方向；打包脚本会检查透明边界、空帧、重复方向、GLB 骨骼与动作数量。
