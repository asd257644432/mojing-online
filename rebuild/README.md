# rebuild/ · 另一条重做线

这个目录是 fork 里**全新增加**的，`../client/` 和仓库根目录原有文件**一个字节都没有改动**。

## 这是什么

在原 three.js 3D 客户端之外，另起的一条 2D 重做线：

- **画面**：Canvas 2D 手绘像素风，照 2011 年页游截图重画，不用 3D 模型、不做现代质感
- **网络**：沿用「客户端只画画面、服务器当裁判」的分工，WebSocket 同步
- **数据**：数据表独立成文件，每条数值标注考据状态

不是要替换 `../client/`，是并行的另一条路。原仓库的技术路线、代码结构、许可声明全部保持原样。

## 怎么跑

需要 Node.js。

```
node web/server/server.js 8080
```

浏览器打开 `http://localhost:8080`。

服务器默认端口 8080，可用命令行参数改。

## 数据表怎么读

每条数值都带状态标记，不是所有数字都已确认：

| 状态 | 含义 |
| --- | --- |
| 已定 | 已经拍板，可以直接用 |
| 图证 | 截图里能直接看到并读出 |
| 推定 | 按比例或规则算出来的，没有直接图证 |
| 未判定 | 还没核，占位用 |

**没有图证的东西一律用占位名，不自己编。** 例如技能名在原始截图里读不出来时，数据表里就叫「技能格01」，不虚构名字。

考据口径见 `docs/INDEX.md` 和 `docs/art/01-资产分区与版权隔离.md`。

### 关于那首背景音乐

`web/client/assets/bgm/island.mp3` 与原版客户端音乐包里的「遗迹之岛」**字节级相同**
（MD5 `9e89f350a0b042591ee8527e270e955a`），未找到单独开放许可。

这一点与根目录 `ASSET_NOTICE.md` 的口径一致：公开可见不等于获得授权。因此单独用一次提交放入，
便于独立回退或删除。移除办法：直接删掉该文件即可 —— 客户端加载失败会静默跳过，其余功能不受影响，只是没有声音。

## 已知问题

1. **数据表存在两份**：`tables/` 是主表，`web/server/data/` 是服务器实际读取的副本，两边内容目前一致。服务器不读 `tables/`，改数值时两份都要改，容易漏。
2. **Godot 方向已暂停**：早期曾尝试用 Godot 4 复刻，相关配置已移除，当前实际运行的是本目录下的网页客户端。
3. 人物、怪物、NPC 已接入重绘素材，与原作形象仍有差距；八方向行走帧未补齐。

> 说明：数据表目录取名 `tables/` 而不是 `data/`，因为仓库根 `.gitignore` 已用 `data/` 排除本地数据目录。
